\section{Common matrix environments}
Use \texttt{bmatrix} for square brackets and \texttt{pmatrix} for parentheses:
\[
  A = \begin{bmatrix}
    2 & 1 \\
    1 & 3
  \end{bmatrix},
  \qquad
  \mathbf{x} = \begin{pmatrix}x_1 \\ x_2\end{pmatrix}.
\]

\section{A system in matrix form}
The equations $2x+y=5$ and $x+3y=7$ can be written as
\[
  A\mathbf{x}=\mathbf{b}, \qquad
  \begin{bmatrix}2&1\\1&3\end{bmatrix}
  \begin{pmatrix}x\\y\end{pmatrix}
  =
  \begin{pmatrix}5\\7\end{pmatrix}.
\]
The determinant is $\det(A)=2\cdot3-1\cdot1=5$, so $A$ is invertible.
Using the inverse,
\[
  \begin{pmatrix}x\\y\end{pmatrix}
  = A^{-1}\mathbf{b}
  = \frac{1}{5}
    \begin{bmatrix}3&-1\\-1&2\end{bmatrix}
    \begin{pmatrix}5\\7\end{pmatrix}
  = \begin{pmatrix}8/5\\9/5\end{pmatrix}.
\]
