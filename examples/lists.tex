\section{Numbered steps}
Use \texttt{enumerate} when order matters:
\begin{enumerate}
  \item Write the source document.
  \item Compile it with a LaTeX engine.
  \item Review the resulting PDF.
\end{enumerate}

\section{Bulleted items}
Use \texttt{itemize} when order does not matter:
\begin{itemize}
  \item Keep examples focused.
  \item Use descriptive labels.
  \item Recompile after making changes.
\end{itemize}

\section{Descriptions}
The \texttt{description} environment is useful for terms and definitions:
\begin{description}
  \item[Source] The editable \texttt{.tex} file.
  \item[Engine] A program such as pdfLaTeX that compiles the source.
\end{description}
