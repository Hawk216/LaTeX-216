The \texttt{listings} package formats source code without requiring shell
escape. The following Python snippet is typeset as text; LaTeX does not execute
it.
\begin{lstlisting}
def square_sum(values):
    # Return the sum of the squares.
    return sum(value ** 2 for value in values)
\end{lstlisting}
