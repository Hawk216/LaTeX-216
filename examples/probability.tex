\section{Sample spaces and events}
A sample space $\Omega$ is the set of all possible outcomes. An event $A$ is a
subset of $\Omega$. If all outcomes are equally likely, then
\[
  P(A)=\frac{|A|}{|\Omega|}.
\]

For a fair six-sided die, $\Omega=\{1,2,3,4,5,6\}$. The event of rolling an
even number is $A=\{2,4,6\}$, so
\[
  P(A)=\frac{|A|}{|\Omega|}=\frac{3}{6}=\frac{1}{2}.
\]

\section{Addition rule}
For any two events $A$ and $B$, the addition rule is
\[
  P(A\cup B)=P(A)+P(B)-P(A\cap B).
\]
The intersection is subtracted once because outcomes shared by both events
are otherwise counted twice.
